# 晚安 · 夜间锁电脑

一个 Windows 上的"晚上不许玩电脑"工具。到点自动锁屏，关不掉、重启也在，到早上自动解除。

它不是一个防破解软件，而是**给未来的自己设一道坎**：晚上 23:00 之后，屏幕会被一张图片占满，任务管理器、Win 键、Alt+Tab 全部失效；你强行结束进程，一分钟内巡逻任务会把它拉起来。

## 功能

- **定时锁屏**：设定时段（可跨天，默认 23:00 – 06:00），到点自动锁、到点自动解除
- **巡查任务**：每隔设定的时间检查一次；该锁却没锁会补上，不在时段内发现残留限制会主动清理
- **应急口令**：按住 Esc 15 秒后输入口令可解锁；口令可设为每次锁屏自动轮换
- **口令推送**：支持钉钉 / 企业微信 / 飞书群机器人和 QQ 邮箱 SMTP，锁定开始时把口令发到手机
- **U 盘钥匙**：U 盘里放一个 `NIGHTGUARD-UNLOCK.txt`，插上自动解锁
- **锁屏信息**：图片下方显示本次锁定时长与剩余时间，或当晚的锁屏时段
- **白天 / 夜间两套配色**，未手动选择时按时间自动切换

## 文件

| 文件 | 作用 |
|---|---|
| `NightLock.ps1` | 控制面板（图形界面）与安装 / 卸载逻辑 |
| `guard.ps1` | 锁屏引擎：全屏遮罩、键盘过滤、定时与巡逻 |
| `notify.ps1` | 通知推送（钉钉 / 企业微信 / 飞书 / QQ 邮箱） |
| `night-lock.png` | 默认锁屏图片 |
| `nightlock.ico` | 应用图标（7 个尺寸） |
| `make-icon.ps1` | 用代码重新绘制图标 |
| `config.example.json` | 配置样例，安装时会复制成 `config.json` |

## 安装

1. 把整个文件夹拷到目标电脑
2. 双击 `一键安装.cmd`（会请求管理员权限）
3. 程序安装到 `C:\ProgramData\GoodNight`，桌面出现「晚安」快捷方式

需要 Windows PowerShell 5.1（Windows 10/11 自带），无需安装任何依赖。

## 用法

打开面板后：

- 第一行：`启动 / 停用`（绿=启动、红=停用）· `立即锁定` + 时长 · `保存`
- 第二行：`预览` · `打开文件夹` · `打开日志`
- 「锁屏设置」页：锁屏时段、巡查间隔、应急口令（含每次轮换）、锁屏图片
- 「通知与解锁」页：选通知方式后只显示该方式需要填的字段

解锁方式：按住 Esc 15 秒输入当次口令、插 U 盘、或等时段结束。

## 注意

- 口令、邮箱授权码等敏感信息保存在 `C:\ProgramData\GoodNight\config.json`（明文）。该文件已在 `.gitignore` 中排除，**不要提交**。
- 开启"每次轮换"后，口令只在锁定开始时生成一次并推送，务必确保推送渠道可用，否则夜间只剩 U 盘这条路。
- 本工具面向自我约束场景，不做对抗性防护；管理员权限下总能绕过。
